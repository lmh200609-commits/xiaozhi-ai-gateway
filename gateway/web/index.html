⚠️ 为什么开发板一直提示“检查新版本失败”？
1. 换了电脑使用：小智开发板芯片内部仍记忆着上一台电脑的旧 IP！在别人电脑上使用时，必须让开发板重新配网并填入上方显示的当前电脑局域网 IP。
2. Windows 防火墙拦截：Windows 默认可能阻止局域网外部设备访问 8001 端口，可在当前电脑以管理员权限执行：netsh advfirewall firewall add rule name="Xiaozhi" dir=in action=allow protocol=TCP localport=8001
3. 路由器 AP 隔离：确保开发板与电脑连接的是同一个 Wi-Fi（且非访客网络或隔离热点）。
• 手机极速配网：开发板通电后，长按 BOOT 键 5 秒进入 AP 配网模式，手机连接小智 Wi-Fi 热点访问 192.168.4.1，在服务器配置中粘贴上方的 WebSocket 地址即可！

📌 为什么在其他电脑或其他网络上小智可能连不上？
1. 黑屏/未启动现象：有时接入 USB 数据线，电脑串口驱动可能使板子处于待机/Bootloader 模式，点击上方【⚡ 软件唤醒开机】或轻按板子侧边 RST 复位键即可瞬间开机；
2. 公司/校园/酒店网络 (AP客户端隔离)：企业级路由器通常开启了“隔离”功能，禁止局域网设备互连，板子无法与电脑通信；
3. 5GHz 频段 Wi-Fi：小智硬件只认 2.4GHz 频段；
4. 旧网络残留：换了电脑或 Wi-Fi 后，必须用数据线连接电脑后点击下方【一键写入】！
👉 最省心推荐方案：电脑和小智同时连手机 2.4G 个人热点（无内网隔离、随身携带走哪都能用）。
