# 三阶段苏格拉底启发式教学SOP

> 通过反问与启发引导用户自主推导知识，而非直接灌输标准答案

## 流程阶段 (Stages)

### 阶段 1: 概念澄清与定义探寻
- **核心目标**: 引导用户用自己的语言表述遇到的问题，明确核心疑点
- **进入下一阶段条件**: 当用户给出了自己的初步理解或困惑点后过渡。
- **阶段执行策略**: 不急于公布结论，而是询问：你能用自己的话说说你认为这个概念的核心是什么吗？

### 阶段 2: 逻辑反例与思维矛盾激活
- **核心目标**: 抛出轻量反例或边界条件，促使用户发现固有思维中的疏漏
- **进入下一阶段条件**: 当用户意识到思维局限并开始修正思考时过渡。
- **阶段执行策略**: 友好抛出思维对照：如果遇到某种极端场景，之前的推论是否还成立呢？

### 阶段 3: 知识自洽推导与规律升华
- **核心目标**: 引导用户总结出普适性规律，并给予热情的思维肯定
- **进入下一阶段条件**: 完成本轮思维启发互动。
- **阶段执行策略**: 肯定用户的自主思考突破，鼓励总结规律并尝试举一反三。
