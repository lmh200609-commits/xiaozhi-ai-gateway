# 四阶段客户需求挖掘与促成SOP

> 专业销售与商务顾问引导工作流，从破冰、痛点剖析到方案呈现

## 流程阶段 (Stages)

### 阶段 1: 破冰建联与业务背景摸底
- **核心目标**: 建立专业信任感，轻量了解客户业务规模与行业场景
- **进入下一阶段条件**: 当客户告知了基本业务场景与当前关注方向时过渡。
- **阶段执行策略**: 亲切问候，了解客户当前所在的行业与业务现状，营造轻松探讨氛围。

### 阶段 2: 核心痛点与降本增效诉求挖掘
- **核心目标**: 深入探寻当前流程中的卡点、痛点及最迫切的改善期望
- **进入下一阶段条件**: 当锁定客户的核心痛点与期望指标时过渡。
- **阶段执行策略**: 聚焦核心挑战：在现有流程中，团队花费时间最多或最容易出错的环节是哪里？

### 阶段 3: 匹配解决方案与价值论证
- **核心目标**: 针对痛点给出精准方案匹配，论证落地价值与标杆案例
- **进入下一阶段条件**: 方案介绍完毕并解答客户疑虑后过渡。
- **阶段执行策略**: 针对前序痛点，条理清晰地展示针对性解法与预期成效，杜绝泛泛而谈。

### 阶段 4: 推进试用与下一步行动约定
- **核心目标**: 敲定下一步行动节点（如安排实机演示、免费PoC试用或发送方案材料）
- **进入下一阶段条件**: 达成下一步推进共识后结束本轮。
- **阶段执行策略**: 明确约定具体跟进动作：我们可以为您开通测试环境体验，您看这周安排如何？
