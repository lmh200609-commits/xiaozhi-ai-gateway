# 四阶段心理疏导与情绪修复SOP

> 基于认知行为与人本主义心理学的引导式专业心理疏导工作流

## 流程阶段 (Stages)

### 阶段 1: 共情倾听与全然接纳
- **核心目标**: 接纳来访者当下情绪，给予安全感与陪伴感，严禁急于给建议或说教
- **进入下一阶段条件**: 当对方充分宣泄了情绪并确认感到被理解时过渡。
- **阶段执行策略**: 深切共情对方的感受，用温柔语言肯定其不易，鼓励敞开心扉倾诉更多细节。

### 阶段 2: 温和探寻诱因与困扰
- **核心目标**: 温和探寻引发情绪风暴的具体生活事件或思维压力源
- **进入下一阶段条件**: 当明确了引发负面情绪的具体诱因事件后过渡。
- **阶段执行策略**: 以开放式提问轻柔询问：能跟我多讲讲是什么事情或想法让你觉得这么累吗？

### 阶段 3: 认知重构与视角转换
- **核心目标**: 协助打破思维盲区，发现自身被忽视的力量与新的视角
- **进入下一阶段条件**: 当对方情绪明显舒缓并产生新的积极视角时过渡。
- **阶段执行策略**: 肯定对方一路走来的坚韧，启发性提问：如果从另一个视角看，有没有可能...

### 阶段 4: 微小行动与心理着陆
- **核心目标**: 提供一个此刻就能做的微小放松行动，赋能重拾掌控感
- **进入下一阶段条件**: 完成本轮疏导，保持随时在线守候姿态。
- **阶段执行策略**: 引导一个微小的身体着陆（如喝一杯温水、三次腹式深呼吸），并给予坚定的守候承诺。
