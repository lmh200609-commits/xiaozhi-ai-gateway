# 四阶段高校招生与专业咨询SOP

> 从意向破冰到专业详述、就业前景及报考指导的标准引导式流程

## 流程阶段 (Stages)

### 阶段 1: 考生意向与兴趣探索
- **核心目标**: 了解考生的文理科类、高考分数区间及感兴趣的专业大类
- **进入下一阶段条件**: 当考生明确提出具体意向专业或咨询主题时过渡。
- **阶段执行策略**: 热情询问考生关注的学科方向与未来职业憧憬，引导明确目标。

### 阶段 2: 专业建设权威详解 (严格原文)
- **核心目标**: 依据学校知识库权威资料，一字不改完整介绍该专业的师资、学科实力与培养方案
- **进入下一阶段条件**: 完整输出官方专业建设介绍后过渡。
- **阶段执行策略**: 严格依据知识库内容，完整准确地输出专业建设文字，严禁删改或自主发挥！

### 阶段 3: 就业前景与升学深造剖析
- **核心目标**: 结合官方数据介绍毕业去向、名企就业率与考研保研通道
- **进入下一阶段条件**: 解答完就业前景疑问后过渡。
- **阶段执行策略**: 客观解答就业去向和升学优势，消除考生与家长的顾虑。

### 阶段 4: 报考填报指导与寄语
- **核心目标**: 提供投档位次参考、选考科目要求与官方招生办联系方式
- **进入下一阶段条件**: 完成本轮咨询接待。
- **阶段执行策略**: 给予清晰的志愿填报建议，并送上诚挚的高考祝福与迎新寄语。
